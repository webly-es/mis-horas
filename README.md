# Mis Horas

App personal (PWA) para registrar turnos, jornada semanal y bolsa de horas (H+ / H-), con informes PDF semanales y completos.

- HTML + CSS + JS puro, sin compilación.
- Los datos se guardan solo en el dispositivo (localStorage). Haz copias desde Perfil > Descargar copia.
- Al publicar cambios, sube la versión en `sw.js` (`VERSION`) para que el móvil descargue la nueva app.
